LAB RBAC

¿En qué consiste el control de acceso basado en roles?

El control de acceso basado en roles (RBAC) es un modelo de seguridad que restringe el acceso a los recursos del sistema en función de los roles asignados a los usuarios. En RBAC, se definen roles específicos con permisos asociados, y los usuarios se asignan a esos roles. Esto permite una gestión más eficiente de los permisos y facilita la administración de la seguridad, ya que los permisos se asignan a roles en lugar de a usuarios individuales.

Investiguen y describan 2 sistemas, uno que aplique RBAC y uno que no. Realicen un análisis de las ventajas y desventajas de cada uno con respecto al control de acceso.

Sistema con RBAC: Microsoft Active Directory

Microsoft Active Directory es un servicio de directorio que utiliza RBAC para gestionar el acceso a recursos en una red. En Active Directory, los administradores pueden crear roles específicos con permisos asociados y asignar usuarios a esos roles. Esto facilita la administración de permisos y mejora la seguridad al garantizar que los usuarios solo tengan acceso a los recursos necesarios para sus funciones.

Sistema sin RBAC: Sistema de archivos tradicional

En un sistema de archivos tradicional, el control de acceso se basa en permisos individuales asignados a cada usuario para cada archivo o directorio. Esto puede resultar en una gestión de permisos más compleja y propensa a errores, ya que los administradores deben asignar permisos a cada usuario individualmente, lo que puede llevar a inconsistencias y dificultades para mantener la seguridad.
