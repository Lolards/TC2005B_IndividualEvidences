Preguntas

1. ¿Que elementos hay que configurar para un entorno de produccion?

Para configurar un entorno de producción, es necesario considerar: la seguridad, el rendimiento, la escalabilidad y la monitorización. Esto incluye configurar firewalls, implementar certificados SSL, optimizar la base de datos, configurar balanceadores de carga, y establecer sistemas de monitoreo para detectar y resolver problemas rápidamente.

2. ¿Que variables de entorno tienes que crear en tu proyecto?

Es importante crear variables para configurar rutas, credenciales, y otros parámetros que puedan cambiar entre entornos (desarrollo, testing, producción).

3. Investiga los tipos de DNS y explícalos

Los tipos de DNS incluyen registros A (dirección IP), CNAME (alias), MX (correo electrónico), TXT (texto), y NS (servidor de nombres). Cada uno tiene un propósito específico en la resolución de nombres de dominio.

4. ¿Qué significa para un dominio cambiar el registro NS a diferencia de los demás?

Cambiar el registro NS implica actualizar los servidores de nombres asociados con un dominio, lo cual afecta cómo se resuelven las solicitudes DNS para ese dominio.

5. Investiga los pros y contras de los certificados SSL gratuitos contra los de pago ¿Qué ventajas y desventajas otorgan? ¿Para cuando se recomendaría usar uno de pago o uno gratuito?

Los certificados SSL gratuitos ofrecen protección básica pero pueden tener limitaciones en funcionalidades y soporte. Los certificados pagados suelen proporcionar mayor seguridad, soporte técnico y características adicionales.
